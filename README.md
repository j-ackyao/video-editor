# video-editor
completely vibe-coded video editor, human-out-of-the-loop, several agents

goal was to create a light-weight video editor that's simple and can compress videos into smaller files deliverable over media platforms

### getting started
not really intended to be maintainable code, just a personal tool

if you really want to use it, you can go to the [releases](https://github.com/j-ackyao/video-editor/releases) and find the compiled `zip`, running `VideoTrim.App.exe` should open out of the box
